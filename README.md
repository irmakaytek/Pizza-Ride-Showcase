# Pizza-Ride-Showcase-
Portfolio Showcase: 'Pizza Ride'

> This is a portfolio showcase for "Pizza Ride", a game I helped produce as part of a two-person collaboration, under the name 'Cautious Games'.
> *(In collaboration with [Ertaç Karagöz](https://github.com/ertackaragoz))*

## About The Game 
You play as an ordinary delivery person. Deliver pizzas to grandmas to earn money, get points to rank up, buy new bikes, accessories and more! But be careful on the road, there is always an obstacle to get on your way!
